# Segun Portfolio

A responsive portfolio website built with Next.js, React and Tailwind CSS.

## Run locally

1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel

Import this GitHub repository into Vercel. Vercel will detect Next.js automatically. Use the default build command `npm run build` and output settings.
